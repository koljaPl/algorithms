# Что вообще значит «автомат» в алгоритмах?

В контексте строк и Trie:

#### автомат = модель, которая читает символы по одному и меняет состояние

То есть это просто:

1. ты в каком-то состоянии,
2. читаешь символ,
3. переходишь в другое состояние.


# Формально (но просто)

Автомат — это:

набор состояний (nodes)
набор переходов между ними (edges)
начальное состояние
иногда — “конечные” состояния (где что-то найдено)


# Интуиция (самое важное)

Представь игру:

ты стоишь в комнате (состояние)
тебе говорят букву
ты переходишь в другую комнату

Это и есть автомат.
