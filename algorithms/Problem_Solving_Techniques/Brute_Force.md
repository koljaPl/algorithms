### Brute Force:

#### Brute Force — это алгоритмический метод, при котором:

генерируются все возможные кандидаты на ответ,
каждый кандидат проверяется на корректность,
среди всех корректных выбирается нужный (минимум, максимум или просто любой подходящий).


#### Суть техники

Можно представить так:

Есть пространство всех решений -> мы просто проходим по нему полностью.

Формально:

если есть множество вариантов S,
brute force рассматривает каждый s ∈ S,
и проверяет условие задачи check(s).

#### Где используется Brute Force

Brute Force применяется, когда:

1. Маленькие ограничения
Если:
n ≤ 20…25 → можно перебор подмножеств (2^n)
n ≤ 1000 → иногда O(n²)
n ≤ 10⁵ → только очень ограниченный перебор (например, O(n))

2. Нет очевидного умного решения
Когда:
задача новая / нестандартная,
нужно сначала понять структуру,
или это этап «наивного решения».

3. Проверка гипотез / бэктрекинг
задачи на комбинации
генерация всех вариантов
Sudoku, permutations, subsets

4. Как базовый шаг к оптимизации
Очень часто:
сначала пишут brute force -> потом улучшают до DP / greedy / two pointers

#### Типичные виды brute force
1. Перебор пар

for i in range(n):
    for j in range(i+1, n):

-> используется в задачах типа:

Two Sum (наивное решение)
поиск пары с условием

2. Перебор всех подмножеств

for mask in range(2^n):

-> subset sum, выбор элементов

3. Перебор перестановок

-> задачи на порядок элементов

4. Полный перебор с проверкой (backtracking)

-> генерируем решения рекурсивно
